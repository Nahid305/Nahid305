## 🚀 Featured Projects

### 🧠 [Semantic SLAM with YOLO](https://github.com/Nahid305/semantic-slam-yolo)
Advanced real-time mapping using SLAM with YOLO object detection.

- 🛠️ Python, OpenCV, PyTorch
- 📌 Combines spatial awareness with object detection for robotics navigation.
- 🧪 Enhanced map accuracy and object annotation in real-time environments.

---

### 💼 [CareerCraft AI](https://github.com/Nahid305/career_recommendation_engine)
Smart career recommendation engine powered by GPT and NLP.

- 🛠️ Streamlit, GPT, NLP
- 📌 ATS-optimized recommendations using profile parsing.
- 🚀 Suggests ideal roles based on your resume and interests.

---

### 🏦 [Smart Loan Predictor](https://github.com/Nahid305/Loan-Eligibility-Prediction)
Loan approval prediction with explainable AI.

- 🛠️ Scikit-learn, Flask, Pandas
- 📌 92% accuracy using Random Forest and SHAP visualizations.
- 🧪 Helps banks assess risk with interpretable insights.

---

### 🚗 [Guardian Drive – Driver Safety Kit](https://github.com/Nahid305/Driver_Safety_Kit)
IoT system to monitor driver alertness and fatigue.

- 🛠️ Raspberry Pi, OpenCV, Arduino
- 📌 Detects drowsiness and sends alerts to reduce road accidents.
- 📈 Real-time monitoring of motion, pulse, and fatigue levels.

---

### 🖼️ [Vision Linguist – Image Caption Generator](https://github.com/Nahid305/Image-Caption-Generator)
Deep learning model to auto-caption images using CNN-LSTM.

- 🛠️ TensorFlow, Keras, NLTK
- 📌 Achieved 85% BLEU score for caption quality.
- 📸 Describes images like a human using computer vision + NLP.
